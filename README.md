# SmartBudgetManagger
A project for managing Budget
SmartBudget Manager
What it does
SmartBudget Manager is an Excel workbook that helps you record monthly income and expenses. It organizes expenses by category, calculates your monthly balance, displays a dashboard and chart, and warns you when spending exceeds the budget limit.

What you need
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
The file SmartBudget_Manager.xlsx.
Workbook sheets
Dashboard: View total income, total expenses, monthly balance, and charts.
Transactions: Enter income and expenses.
Categories: View the predefined expense categories, such as Food, Transport, Rent, Health, and Education.
Get started
Open SmartBudget_Manager.xlsx.
Select Transactions.
Enter each transaction in the appropriate row and columns. Include the date, description, category, and amount in the correct income or expense column.
Select Dashboard to review the updated totals and chart.
Check the budget warning and save your changes.
Important
Do not overwrite cells containing formulas. Enter numbers as amounts and choose a category that matches the transaction. Save a backup copy regularly.
